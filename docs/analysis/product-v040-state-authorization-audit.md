# Product v0.4 PR-C 状态绑定与授权审核

PR-C 在独立只读状态采集、配置基线绑定、批准消费和写意图之间建立事务边界。它仅使用离线假适配器验证行为，没有真实配置控制适配器、执行器或环境写入。PR-A、PR-B 已分别作为 #91、#92 合并；本阶段的 GitHub CI 和合并仍待完成。

## 已实现的授权边界

`TrustedStateBindingV1` 是可信进程配置，不由 HTTP 请求提供。它绑定环境、资源所有权、目标身份、控制接口身份、Product Active Baseline、配置基线与精确故障配置摘要，以及固定注册表。`CurrentStateProviderV1` 只有只读方法；默认 API 没有配置该 provider，尝试创建将持久化拒绝结果，授权和写意图均为零。

新状态必须在批准之后采集，使用 UTC 时间，且验证时不超过 30 秒。公开安全的采集对象进入现有 CAS；快照绑定这些对象摘要以及 Incident、候选、批准和可信配置的标识与摘要。状态采集在 SQLite 写事务之前完成；进入事务后重新检查持久化诊断、证据、Active Baseline、批准有效性和活动尝试数。耗时校验后再次刷新时间，不能使用请求开始时的旧时间通过授权或写意图门禁。

单个 BEGIN IMMEDIATE 事务持久化状态快照、最长五分钟且不晚于批准到期的授权、尝试、批准消费、不可变创建记录和审计事件。唯一约束禁止同一批准再次获得授权；部分唯一索引禁止同一环境与 Payment 目标同时存在两个活动尝试。原批准对象和授权对象保持不可变，消费状态由独立记录表达。公开批准状态会显示 CONSUMED；内部有效性检查仍须与事务内的消费归属检查一起使用。

幂等键绑定不可变创建记录。相同键与请求返回同一尝试的当前状态，不重新授权；不同请求稳定冲突。即使 provider 已不可用，已完成的幂等创建仍能返回原尝试。没有批准、没有有效状态或没有可信控制绑定时，不会获得授权。

## 租约、写意图和历史

租约最长 30 秒且不晚于授权到期。写意图前可以回收过期租约；新持有者获得新的随机标识与递增代次，旧持有者被拒绝。写意图提交前再次采集状态，复查诊断、基线、批准、活动尝试和授权消费；在最终插入前重新检查时间、租约、批准、授权和观测新鲜度。

写意图与授权消费在同一事务提交，数据库分别约束每个尝试及授权至多一个写意图。写意图绑定其前一尝试版本、授权和提交前快照。提交写意图只持久化意图，不调用环境适配器，因此 PR-C 的环境写入仍为零。

每个尝试版本均以不可变记录保存。当前投影绑定该版本；审计事件通过哈希链引用可解析的历史版本，空历史、缺失版本和截断尾部都会被拒绝。接受路径记录候选、批准、活动事务、所有权、基线、配置变化、状态绑定及授权门禁；拒绝路径保留已完成门禁和失败门禁。耗时使用单调时钟测量，事件使用 UTC 时间。

写意图后不允许回收租约或自动重试。租约过期后的只读核对会保留采集证据引用并转为 OUTCOME_UNKNOWN / ESCALATE_HUMAN。即使观测到配置已经恢复，没有有效执行回执也不能回写 RECOVERED。PR-C 的状态转换表不提供 EXECUTING、APPLIED 或 RECOVERED 的合法入口；这些路径由后续执行器与验证器阶段实现。

## 兼容性与验证

`app.py` 的改动仅用于挂载默认无 provider 的尝试仓库；这是必要的 Product 组合入口。附加 schema 2 保留 PR-B schema 1 的定义、摘要和数据，仍使用原 Product schema 9。测试覆盖升级后旧记录保持原字节，以及 SQLite 外键、WAL、并发唯一性和事务回滚。没有修改历史迁移或冻结证据。

本地验证：233 项 Product/v0.4 测试通过；Goal 指定范围的 Ruff 通过；mypy 通过，检查 227 个源文件；404 个冻结历史文件、Goal 原始摘要和 upstream 指针校验通过；`git diff --check` 通过。

独立审查最初发现并复现了两项问题：耗时校验后的旧时间可越过有效期；尝试父摘要与历史版本绑定不完整。两项均已修复。独立复现中，31 秒延迟拒绝授权，121 秒延迟拒绝写意图，写意图数均为零。最终独立审核为 PASS / Must Fix 0 / Claim Accuracy PASS，独立运行 100 项 v0.4 测试通过。

当前没有真实执行、真实回执、恢复窗口或 live recovery 证据。真实适配器的所有权证明、进程隔离与提交后执行前复核属于 PR-D；唯一受授权的故障 campaign 属于 PR-E。PR-C 的离线通过不代表总体 Goal 完成，也不提供外部副作用的 exactly-once 保证。
