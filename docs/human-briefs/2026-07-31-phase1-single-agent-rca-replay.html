实现范围

  • 一个 SingleAgent，根据观察结果动态选择 Metrics、Logs、 Traces、Changes 四个只读 typed tools。
  • run-scoped Evidence Store 分配和解析可验证 evidence://<run-id>/<source>/<sequence> 引用。
  • 结构化 RCA_CONFIRMED、NEED_MORE_EVIDENCE、 ABSTAIN，包含有界且不作为 Evidence 的 decision_rationale。
  • alert_source_service 为 optional、non-authoritative； 多数案例为空，frontend decoy 案例故意提供错误 hint。
  • scripted adapter 是 pytest、replay smoke 和 evaluation 的默认模型； OpenAI-compatible gateway 仅由显式 provider smoke opt in。
  • evaluation 在 python -I 的 src-only 子进程执行 Agent； import、filesystem 与 audit guards 对 evaluator-only 路径 fail closed。 父 evaluator 仅在重新验证 AgentRunReport 后读取 ground truth。

Phase 0 与范围边界

Phase 0 的历史结论和 live evidence 未被重写；protected trees/blobs 与批准 base 完全一致。Phase 0 仍不完整，PR #1 仍为 Draft / REVIEW_REQUIRED。本 Phase 1 不等待或修复 live integration，也没有运行 Docker。

本分支未实现 Multi-Agent、Commander、Judge、Remediation、live observability 或模型训练。Phase 2 仍未实现。

不能扩大声称的事项

  • 真实 provider smoke 只是两个指定 gate cases，不能声称它取得七案例 Decision Accuracy 7 / 7，也不能推广为一般模型质量或生产可用性。
  • evaluator capability isolation 当前在 macOS 使用 sandbox-exec / Seatbelt；没有经过证明的非 Darwin sandbox backend 时，evaluation 会 fail closed，而不是降级运行。
  • 不能把 1 / 1 decoy case 推广为一般化 decoy robustness。
  • 不能把 replay fixture evaluation 解释为 live observability 或生产验证。
  • injected transport contract tests 与这次真实 gateway 两案例 smoke 是两类证据， 不能互相替代或合并计算。
  • 不能用非确定的真实 wall-clock 数值替代 deterministic semantic projection。
