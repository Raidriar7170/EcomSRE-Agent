机器可读 readiness： main_evaluation_ready = true、ablation_slot_count = 38、 ablation_implementation_available = false、 ablation_evidence_available = false、 ablation_primary_eligible = false、 ablation_disposition = ABLATION_NOT_IMPLEMENTED_IN_FROZEN_HARNESS。 这 38 个 slots 不是已完成实验、模型证据或 ablation 结果。

冻结清单路径说明

协议冻结器会把 config/phase5b/**/*.json 的完整 path set 视为不可变； 因此直接新增原建议路径 config/phase5b/execution-freeze.v1.json 会使既有 make phase5b-preflight fail closed。执行控制面清单放在独立的 config/phase5b-execution/execution-freeze.v1.json，不修改协议冻结器或 原 freeze manifest；清单仍绑定协议 commit、公开 seal/hash、schedule、ablation、 全部新 harness 文件、Makefile、Provider/budget/pacing、sandbox 与 checkpoint policy。

  • 绿色测试不授权正式 180-run hidden primary Provider execution；仍须等待 freeze PR 合并及精确 Phase 5B-2B 授权 AUTHORIZE_PHASE5B_V1_SCORED_EXECUTION。
